## Intuition

Suppose a fixed weighted tree has 200,000 vertices. Each query marks a handful of vertices and asks for the sum of distances over all unordered pairs of marked vertices. A full tree DP scans 200,000 vertices per query. Even after preprocessing LCA, asking for each pair's distance takes quadratically many pair queries.

A **virtual tree** keeps the marked vertices (called *terminals*) and the junctions where their paths meet. It replaces each chain between retained vertices with a single weighted edge. With `k` distinct terminals, there are at most `2k - 1` retained vertices. A bottom-up pass on that small tree can account for all pairs through edge contributions.

## Definition

Root the original tree once. For a nonempty terminal set `S`, keep every terminal and the original-tree LCA of every pair of terminals. The virtual root is the LCA of all of `S`, which is the terminal itself for a singleton. Each other retained vertex attaches to its deepest retained **strict** ancestor. For an empty set, return an empty virtual tree.

For a virtual edge from ancestor `p` to descendant `v`, use weight `dist_root[v] - dist_root[p]`, the sum along the original `p`–`v` path. Paths between terminals go through their retained LCA. Expanding the virtual edges on such a path gives exactly the original path, so terminal distances are preserved.

### Why adjacent LCAs suffice

Sort the distinct terminals by DFS entry time `tin`. Consider any pair with LCA `a`. If `a` is a terminal, the construction already keeps it. Otherwise the two terminals lie in different child subtrees of `a`. Every child subtree occupies one contiguous DFS interval, and the entire subtree of `a` occupies one interval too. In the sorted terminal list, take the last terminal in the earlier pair member's child subtree and the first terminal in the next nonempty child subtree of `a`. These two entries are consecutive in the full list, and their LCA is `a`.

Thus the terminal set plus the LCAs between consecutive terminals gives exactly the required vertex set. There are at most `k - 1` such LCAs for `k > 0`, even before deduplication.

### Stack construction

1. Sort the terminals by `tin`, compute the consecutive LCAs, then deduplicate and sort the combined set by `tin` again.
2. Scan the combined order. For each vertex `v`, pop while the stack top is outside the ancestor chain of `v`. Check ancestry with `tin[p] <= tin[v] < tout[p]`, using an exclusive exit boundary.
3. If a top remains, emit an edge from it to `v`. Push `v`.

Every retained strict ancestor of `v` appears earlier in preorder and stays on the stack until the scan leaves its subtree. Once a vertex is popped, its DFS interval has ended for the rest of the scan. After the pops, the top is therefore the deepest retained ancestor. The first vertex is the virtual root, and each vertex is pushed once and popped at most once.

Binary lifting takes `O(n log n)` time and space to preprocess a tree of `n` vertices. After deduplication, each query takes `O(k log k + k log n)` time and `O(k)` extra space. Reading and deduplicating an input list of `m` entries also costs `O(m)` expected time.

To sum distances, let `c` be the number of terminals below a virtual edge, counting its child endpoint if marked. Taking one terminal from each side gives `c * (k - c)` unordered pairs whose paths use that edge. Each such pair contributes the edge weight once. Compute `c` by adding child counts to parents in reverse preorder.

| Virtual edge | Weight | `c` | Contribution |
| --- | ---: | ---: | ---: |
| `1 → 2` | 3 | 3 | 9 |
| `2 → 4` | 5 | 1 | 15 |
| `2 → 5` | 6 | 1 | 18 |
| `1 → 7` | 7 | 1 | 21 |

The total is **63**. The count below `1 → 2` includes terminal `2` as well as `4` and `5`.

<CodeRunner language="python" code={`from random import Random


class Tree:
    def __init__(self, n, edges):
        self.adj = [[] for _ in range(n)]
        for u, v, weight in edges:
            self.adj[u].append((v, weight))
            self.adj[v].append((u, weight))

        self.tin = [0] * n
        self.tout = [0] * n
        self.dist_root = [0] * n
        parent = [0] * n
        timer = 0
        stack = [(0, 0, False)]
        while stack:
            v, p, exiting = stack.pop()
            if exiting:
                self.tout[v] = timer
                continue
            parent[v] = p
            self.tin[v] = timer
            timer += 1
            stack.append((v, p, True))
            for child, weight in reversed(self.adj[v]):
                if child != p:
                    self.dist_root[child] = self.dist_root[v] + weight
                    stack.append((child, v, False))

        self.up = [parent]
        for _ in range(1, n.bit_length()):
            previous = self.up[-1]
            self.up.append([previous[p] for p in previous])

    def is_ancestor(self, u, v):
        return self.tin[u] <= self.tin[v] < self.tout[u]

    def lca(self, u, v):
        if self.is_ancestor(u, v):
            return u
        for jump in reversed(self.up):
            if not self.is_ancestor(jump[u], v):
                u = jump[u]
        return self.up[0][u]

    def virtual_tree(self, terminals):
        ordered = sorted(terminals, key=self.tin.__getitem__)
        retained = set(ordered)
        for u, v in zip(ordered, ordered[1:]):
            retained.add(self.lca(u, v))

        vertices = sorted(retained, key=self.tin.__getitem__)
        stack = []
        edges = []
        for v in vertices:
            while stack and not self.is_ancestor(stack[-1], v):
                stack.pop()
            if stack:
                p = stack[-1]
                edges.append((p, v, self.dist_root[v] - self.dist_root[p]))
            stack.append(v)
        return vertices, edges

    def pair_distance_sum(self, marked):
        terminals = set(marked)
        k = len(terminals)
        vertices, edges = self.virtual_tree(terminals)
        count = {v: int(v in terminals) for v in vertices}
        total = 0
        # Edges were emitted in child preorder, so children contribute first here.
        for p, v, weight in reversed(edges):
            c = count[v]
            total += weight * c * (k - c)
            count[p] += c
        return total


def brute_sum(adj, marked):
    terminals = set(marked)
    total = 0
    for start in terminals:
        stack = [(start, -1, 0)]
        while stack:
            v, p, distance = stack.pop()
            if v > start and v in terminals:
                total += distance
            for child, weight in adj[v]:
                if child != p:
                    stack.append((child, v, distance + weight))
    return total

assert vertices == [1, 2, 4, 5, 7]
assert edges == [(1, 2, 3), (2, 4, 5), (2, 5, 6), (1, 7, 7)]
answer = example.pair_distance_sum(terminals)
assert answer == brute_sum(example.adj, terminals) == 63
print("Virtual edges (parent, child, weight):", edges)

## Pitfalls

- **Use DFS entry order for both sorts.** Vertex labels and depths can interleave sibling subtrees, breaking the adjacent-LCA argument and the stack invariant.
- **Distinguish terminals from retained junctions.** An added LCA starts with count zero unless the query marks it. Deduplicate input when the query has set semantics. If repeated entries represent distinct tokens, keep one vertex structurally and initialize its count to its multiplicity.
- **Choose the query root deliberately.** The worked example starts at `1`. If a DP needs paths to the original root, include that root in the construction and count it as a terminal only when marked.
- **Store the path aggregate your DP needs.** Root-distance subtraction gives path sums. For minimum edge weight, query the minimum along each compressed path, for example with a minimum table alongside binary lifting.
