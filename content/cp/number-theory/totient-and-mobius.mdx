## Intuition

Many counting questions ask about numbers that **do not share a factor**: how many fractions are in lowest terms, how many pairs are coprime, how many numbers below `n` have a certain gcd with `n`. The same two tools answer them:

- **Euler's totient** `phi(n)`: how many integers in `1..n` are coprime to `n`.
- **The Moebius function** `mu(n)`: the signs that make inclusion and exclusion over prime factors work, in a form you can sum over all divisors at once.

Both are **multiplicative** (they respect coprime factorisation), so one **sieve** computes them for every number up to `N` in `O(N)`.

## Euler's totient

`phi(n)` counts the integers `1 <= k <= n` with `gcd(k, n) = 1`. Examples: `phi(12) = 4` (1, 5, 7, 11), `phi(13) = 12`, `phi(1) = 1`.

- For a prime `p`: `phi(p) = p - 1`. For a prime power: `phi(p^k) = p^k - p^(k-1) = p^(k-1) (p - 1)` (remove the multiples of `p`).
- **Multiplicative:** if `gcd(a, b) = 1`, then `phi(a b) = phi(a) phi(b)`.
- Hence, from the factorisation `n = p1^e1 ... pk^ek`:

```text
phi(n) = n * (1 - 1/p1) * (1 - 1/p2) * ... * (1 - 1/pk)
```

Compute it as `result = n; for each prime p | n: result -= result / p` (do the division before the multiplication to avoid fractions).

**Euler's theorem.** If `gcd(a, n) = 1`, then `a^phi(n) = 1 (mod n)`. Fermat's little theorem is the case `n = p`. Consequences:

- The inverse of `a` modulo `n` is `a^(phi(n) - 1)`, an alternative to extended Euclid.
- Huge exponents shrink: for `gcd(a, n) = 1`, `a^b = a^(b mod phi(n)) (mod n)`.
- Without coprimality, for `b >= log2(n)`: `a^b = a^(b mod phi(n) + phi(n)) (mod n)` (the generalised Euler theorem).

**Gauss's identity.** `sum of phi(d) over all divisors d of n = n`. (Each of the fractions `k/n` reduces to a unique `a/d` with `d | n` and `gcd(a, d) = 1`.)

**Where it appears.**

- Reduced proper fractions with denominator up to `n`: `phi(2) + ... + phi(n)` (Farey sequence length minus a constant).
- Coprime ordered pairs in `[1, n]^2`: `2 (phi(1) + ... + phi(n)) - 1`.
- `sum over i of gcd(i, n) = sum over d | n of d * phi(n / d)`.

## The Moebius function

```text
mu(1) = 1
mu(n) = (-1)^k   if n is a product of k distinct primes
mu(n) = 0        if some prime square divides n
```

Its defining property: `sum of mu(d) over d | n` equals `1` when `n = 1` and `0` otherwise. This is inclusion-exclusion in disguise: to test "no common prime factor", add the subsets of primes with alternating signs; squares never appear in the subsets, so they get `0`.

**Moebius inversion.** If `F(n) = sum of f(d) over d | n` for all `n`, then

```text
f(n) = sum over d | n of mu(n / d) * F(d)
```

For gcd counting: let `F(k)` be the number of pairs where `k` divides both numbers (easy: `floor(n/k) * floor(m/k)`), and `f(k)` the number with gcd exactly `k`. Then `F(k) = sum of f(j k)` over multiples, and inversion gives

```text
f(1) = number of coprime pairs (a <= n, b <= m) = sum over d >= 1 of mu(d) * floor(n/d) * floor(m/d)
```

## Floor-division blocks

The sum has `min(n, m)` terms, but `floor(n/d)` takes only about `2 sqrt(n)` distinct values. For fixed `l`, the values `floor(n/d)` and `floor(m/d)` are both constant until `r = min(n / floor(n/l), m / floor(m/l))`. With prefix sums `M(x) = mu(1) + ... + mu(x)`:

```text
l = 1
while l <= min(n, m):
    a = n / l;  b = m / l
    r = min(n / a, m / b)
    total += (M(r) - M(l - 1)) * a * b
    l = r + 1
```

That answers one query in `O(sqrt n)` after an `O(N)` sieve, so thousands of queries are fine.

## Example, step by step

Count coprime pairs with `n = m = 4`.

- `mu(1) = 1`, `mu(2) = -1`, `mu(3) = -1`, `mu(4) = 0`.
- `d = 1`: `+ 4 * 4 = 16`. `d = 2`: `- 2 * 2 = -4`. `d = 3`: `- 1 * 1 = -1`. `d = 4`: `0`.
- Total `16 - 4 - 1 = 11`. By the totient formula: `2 (phi(1) + phi(2) + phi(3) + phi(4)) - 1 = 2 (1 + 1 + 2 + 2) - 1 = 11`.

## The linear sieve

One pass computes the smallest prime factors and, with them, `phi` and `mu` for everything up to `N`. Each composite `i * p` is generated exactly once, by its smallest prime `p`:

- If `p` does **not** divide `i`: `phi(i p) = phi(i) (p - 1)`, `mu(i p) = -mu(i)`.
- If `p` **divides** `i`: `phi(i p) = phi(i) p`, `mu(i p) = 0`, and the inner loop stops.

```python
phi = [0] * (N + 1)
mu = [0] * (N + 1)
phi[1] = mu[1] = 1
comp = [False] * (N + 1)
primes = []
for i in range(2, N + 1):
    if not comp[i]:
        primes.append(i)
        phi[i], mu[i] = i - 1, -1
    for p in primes:
        if i * p > N:
            break
        comp[i * p] = True
        if i % p == 0:
            phi[i * p] = phi[i] * p
            mu[i * p] = 0
            break
        phi[i * p] = phi[i] * (p - 1)
        mu[i * p] = -mu[i]

def phi_single(n):                       # one number, by trial division
    result, x, p = n, n, 2
    while p * p <= x:
        if x % p == 0:
            while x % p == 0:
                x //= p
            result -= result // p
        p += 1
    if x > 1:
        result -= result // x
    return result
```

## Which tool

| question | formula |
| --- | --- |
| numbers up to `n` coprime to `n` | `phi(n)` |
| inverse of `a` modulo `n`, coprime | `a^(phi(n) - 1) mod n` (or extended Euclid) |
| `a^b mod n` with a huge `b` | reduce `b` modulo `phi(n)` (add `phi(n)` back if not coprime and `b` is large) |
| reduced fractions with denominator `<= n` | `phi(2) + ... + phi(n)` |
| coprime pairs in `[1,n] x [1,m]` | `sum of mu(d) floor(n/d) floor(m/d)` |
| pairs with gcd exactly `k` | coprime pairs in `[1, n/k] x [1, m/k]` |
| `sum of gcd(i, n)` | `sum over the divisors d of n of d * phi(n/d)` |
| triples or tuples with gcd 1 | `sum of mu(d) floor(n/d)^t` |
| recover `f` from divisor sums `F` | Moebius inversion |

## Pitfalls

1. **Computing `phi` with floating point** (`n * (1 - 1/p)`). Use integer `result -= result / p`.
2. **Not removing repeated primes.** In trial division, divide `x` by `p` until it no longer divides, then apply the factor once.
3. **The leftover factor.** After the loop, if `x > 1` it is a prime above `sqrt(n)`; apply it.
4. **Using Euler's reduction when `gcd(a, n) > 1`** without the correction term `+ phi(n)`.
5. **Block boundaries.** `r = min(n / (n / l), m / (m / l))`; dividing by zero when `l > n` happens if you forget the `l <= min(n, m)` condition.
6. **Overflow.** `floor(n/d) * floor(m/d)` is up to `10^14` for `n = m = 10^7`, and the sum is bigger: use 64-bit integers.
7. **Sieve bounds.** The sieve must reach `max(n, m)` over all queries, not just the first.
8. **Off-by-one in the sum** for pairs: `d` goes up to `min(n, m)`, not `n`.
