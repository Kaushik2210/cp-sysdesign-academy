## Intuition

Suppose volunteers can each staff one booth, and each booth needs one volunteer. If a volunteer finds every compatible booth occupied, try moving one of its occupants to another booth. That move may require another move. If the chain ends at an empty booth, everyone already assigned keeps a booth and one more volunteer gets an assignment.

## Definition

In a bipartite graph the vertices are split into a left side `L` and a right side `R`. Every edge joins one vertex from each side. A **matching** `M` is a set of edges with disjoint endpoints. A vertex with no edge in `M` is **free**. A **maximum matching** has the greatest possible size. A **maximal matching** has no edge you can add directly. Greedily matching free pairs guarantees maximality and can get stuck below the maximum.

An **augmenting path** is a simple path from a free left vertex to a free right vertex. It alternates between edges outside `M` and edges in `M`, starting and ending with edges outside `M`. To find one, follow unused edges left to right and matched edges right to left. Flipping the path removes its matched edges and adds its unused edges. Each internal vertex trades one partner for another, and both endpoints gain partners, so the matching grows by one edge.

**Berge's lemma.** A matching is maximum exactly when it has no augmenting path. For the converse to the flip argument, suppose a larger matching `N` exists. Keep only the edges that belong to exactly one of `M` and `N`. Each vertex has at most one edge from each matching, so every nontrivial component is an alternating path or cycle. A cycle contributes equally to both matchings. Since `N` has more edges overall, some path has one extra edge from `N`. Its two endpoints are free in `M`, so that path augments `M`.

### Certify the answer with a vertex cover

A **vertex cover** is a set of vertices containing at least one endpoint of every edge. Any cover must contain at least one distinct vertex per matching edge, so its size is an upper bound on the size of every matching. A valid matching and a valid cover of equal size certify both optimal answers.

With the final matching fixed, start an alternating search from **all** free left vertices. Follow unused edges to the right and matched edges to the left. Call the reached sets `Z_L` and `Z_R`. Choose every left vertex outside `Z_L` and every right vertex inside `Z_R`.

In the example, the only free left vertex is D. The search follows `D → 0 → C`, so `Z_L` contains C and D and `Z_R` contains booth `0`. The cover consists of A, B, and booth `0`. A and B cover every edge in their rows, and `0` covers both remaining edges.

To see why the construction works, take any edge `(u, v)` with `u` in `Z_L`. If the edge is unused, the search reaches `v` from `u`. If the edge is matched, `u` was reached through its unique mate `v`, since a matched left vertex cannot be a root. Either way, `v` belongs to `Z_R`. Edges whose left endpoint lies outside `Z_L` are covered by that endpoint.

For a matched edge its endpoints are either both reached or both unreached, since reaching its right endpoint also reaches its left mate. The cover therefore takes exactly one endpoint of each matched edge. Every free left vertex is reached, and every free right vertex is unreached because reaching one would give an augmenting path. The cover contains only matched vertices and has size `|M|`. This proves the bipartite matching and vertex-cover equality in Kőnig's theorem.

## Code

Kuhn's algorithm starts a DFS once per left vertex. `mate_r[v]` holds the left owner of right vertex `v`, or `-1` if it is free. When DFS tries an occupied right vertex, it asks whether the owner can move. A successful call writes its new assignment on the way back up. A failed call leaves the matching unchanged. Skipping a right vertex already owned by the current left vertex enforces the unused-edge rule. Marking each left vertex once per search prevents cycles, and using the root index as a timestamp starts a fresh search without clearing the array.

One attempt per left vertex suffices by a prefix invariant. Before adding the next left vertex `u`, the current matching is maximum on the earlier vertices. Adding `u` can increase the optimum by at most one, because deleting `u` from any matching removes at most one edge. Any augmenting path after adding `u` must use it, since there was no such path before. As `u` is free, it must be the left endpoint. The DFS either finds that one improvement or proves the old size still optimal.

Reconstruct the left mates by inverting the final `mate_r` array, then emit pairs in left index order. The cover uses a fresh traversal of the final matching. The demo accepts `adj[u]` as a list of right indices in `0..n_right-1`. Left and right indices are zero-based and belong to separate sides.

<CodeRunner language="python" code={`def kuhn(adj, n_right):
    n_left = len(adj)
    mate_r = [-1] * n_right
    seen = [-1] * n_left

    def augment(u, stamp):
        if seen[u] == stamp:
            return False
        seen[u] = stamp

        for v in adj[u]:
            owner = mate_r[v]
            if owner == u:
                continue
            if owner == -1 or augment(owner, stamp):
                mate_r[v] = u
                return True
        return False

    for u in range(n_left):
        augment(u, u)

    mate_l = [-1] * n_left
    for v, u in enumerate(mate_r):
        if u != -1:
            mate_l[u] = v
    pairs = [(u, v) for u, v in enumerate(mate_l) if v != -1]

    reached_l = [v == -1 for v in mate_l]
    reached_r = [False] * n_right
    stack = [u for u in range(n_left) if reached_l[u]]
    while stack:
        u = stack.pop()
        for v in adj[u]:
            if mate_l[u] == v or reached_r[v]:
                continue
            reached_r[v] = True
            owner = mate_r[v]
            if owner != -1 and not reached_l[owner]:
                reached_l[owner] = True
                stack.append(owner)

    cover_l = [u for u in range(n_left) if not reached_l[u]]
    cover_r = [v for v in range(n_right) if reached_r[v]]
    return pairs, cover_l, cover_r


def check(adj, n_right, expected_size):
    pairs, cover_l, cover_r = kuhn(adj, n_right)
    left, right = set(cover_l), set(cover_r)
    assert len(pairs) == expected_size
    assert len({u for u, v in pairs}) == len(pairs)
    assert len({v for u, v in pairs}) == len(pairs)
    assert all(0 <= u < len(adj) and 0 <= v < n_right and v in adj[u]
               for u, v in pairs)
    assert len(left) == len(cover_l) and len(right) == len(cover_r)
    assert all(0 <= u < len(adj) for u in left)
    assert all(0 <= v < n_right for v in right)
    assert all(u in left or v in right for u, row in enumerate(adj) for v in row)
    assert len(left) + len(right) == len(pairs)
    return pairs, cover_l, cover_r

Let `n_L` and `n_R` be the side sizes, and `m` the number of adjacency entries. Each DFS scans at most `m` entries. Initialisation, reconstruction, and the cover traversal take `O(n_L + n_R + m)`, giving `O(n_L * m + n_L + n_R)` total time and `O(n_L + n_R)` auxiliary space, including the recursion stack. If the sides are interchangeable, using the smaller side for the DFS roots improves the worst-case product. For larger graphs, Hopcroft–Karp batches shortest augmenting paths and runs in `O((m + n) * sqrt(n))` time for `n = n_L + n_R`.

## Pitfalls

- **Sharing visited marks across roots.** A later volunteer may need to move an owner visited in an earlier search. The worked example needs to revisit both A and B when processing C.
- **Overwriting an occupied right vertex early.** Commit its new owner only after the old owner finds another partner. Read the final pair list after all searches finish, since later successes can move earlier matches.
- **Reusing DFS marks for the cover.** The cover needs reachability from every free left vertex in the final matching. Follow only unused edges going right and only matched edges going left.
- **Ignoring recursion depth.** A single Python search can descend through a linear number of left vertices. For deep instances, use explicit DFS frames that track the next neighbor and the edges to flip on success, or choose an implementation with a suitable stack strategy.

2. **Cover inspection alerts.** A rectangular board has flagged cells. Selecting a row or a column covers all flags on that line. Given the flagged coordinates, output the fewest selected lines, their identities, and an equally large set of flagged cells with no shared row or column. Explain how the two outputs certify the answer.
3. **Explain a staffing shortfall.** Given shift-to-volunteer compatibility, either assign every shift a distinct volunteer or return a set `S` of shifts with fewer than `|S|` compatible volunteers in total. Try `S = Z_L` after a maximum matching. Show that its neighbor set is `Z_R` and count how many vertices of `S` are matched.
4. **Limit the longest walk.** Each permitted courier-to-locker pair has a nonnegative travel time. Find the smallest time limit that allows every courier to get a distinct locker, or report that it is impossible. Return the pairs at the chosen limit. Prove the feasibility predicate is monotone on the sorted distinct times, and handle the case of zero couriers.
